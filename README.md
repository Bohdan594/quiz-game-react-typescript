# Quiz App

> A simple quiz application built with React, TypeScript, and Context API. Quiz questions are fetched from the Open Trivia Database (OpenTDB) API.

# 🚀 Features

- Fetches questions from OpenTDB API
- Multiple-choice questions
- Score tracking
- Responsive UI
- Global state management with Context API

# 🛠️ Tech Stack

- React
- TypeScript
- Context API
- OpenTDB API
